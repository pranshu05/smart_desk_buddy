1. SHARED CONTRACT FUNCTIONS & FRAMES
------------------------------------------------------------------------
Part            Provided By         Contract Function / Definition
------------------------------------------------------------------------
Window          Pransu (ui.py)      build_window() -> (window, face, frames)
                                    where frames contains 3 empty frames:
                                    'sensors', 'chat', 'settings'

Face            Pransu (face.py)    face.set_emotion(name)
                                      Changes facial expression
                                    face.say(text)
                                      Displays line in speech bubble,
                                      moves mouth, reverts after ~3 sec

Summary screen  Pransu (summary.py) show_summary(log)
                                      Draws end-of-session screen from
                                      event log

Engine          Pranshu (engine.py) Receives sensor/timer/chat events,
                                    decides reaction using rules.py,
                                    and calls face.set_emotion() and
                                    face.say()

Sensor buttons  Pranshu (sensors.py) Fills the 'sensors' frame with buttons
                                     and keyboard shortcuts; sends events
                                     to engine

Chat box        Pranshu             Fills the 'chat' frame with chat box
                (assistant.py)      woken by "Hi ESP"

Settings panel  Pranshu             Fills the 'settings' frame with
                (settings.py)       strictness levels, sound on/off,
                                    and sensor on/off switches

Event log       Pranshu (engine.py) List of (minute, event_name) pairs:
                                    e.g. [(3, 'FIDGET'), (7, 'TAB_SWITCH'),
                                          (14, 'SEAT_LEAVE')]

------------------------------------------------------------------------
2. SHARED WORD LISTS
------------------------------------------------------------------------
Events:
  - SESSION_START
  - SEAT_LEAVE
  - SEAT_RETURN
  - FIDGET
  - TAB_SWITCH
  - PHONE
  - BREAK_REQUEST

Emotions:
  - idle      (Open eyes, slow blink)
  - focus     (Eyes half-closed and calm, no blinking for longer)
  - side_eye  (Pupils shifted to one side, one brow slightly raised)
  - talking   (Mouth opens and closes while text is shown)
  - happy     (Eyes curved like a smile)
  - sleepy    (Low eyelids, very slow blink)

Strictness Levels:
  - Silent    (Face changes only, no spoken lines)
  - Gentle    (Default companion tone, never nagging)
  - Cheeky    (Playful lines)

------------------------------------------------------------------------
3. DEMO MODE & TIMINGS
------------------------------------------------------------------------
  - Normal Mode: 25 minutes focus, 5 minutes break
  - Demo Mode:   60 seconds focus, 15 seconds break
  - Rule: "Take a break now" (BREAK_REQUEST) must ALWAYS be accepted.
  - Rule: During a break, the Buddy never reacts to movement.
